# Instance GMV / ASERGMV - Grande Muraille Verte ## Contexte Cette instance de SmartPointage est adaptée pour l'**Agence Sénégalaise pour la Reforestation et la Grande Muraille Verte (ASERGMV)**. Elle suit les jeunes Xëyu Ndaw Ñi (Jeunes Planteurs) dans les zones de reforestation. ## Terminologie spécifique | Terme standard | Terme GMV | |----------------|-----------| | Agence | Zone / Secteur | | Agents | Jeunes Xëyu Ndaw Ñi | | Pointeur | Chef de secteur | | Directeur Régional | Inspecteur régional | | Admin | Coordinateur zone | | Superadmin | Direction ASERGMV | ## Zones configurées ``` Saint-Louis: - GMV-SL-RAO: Zone Rao - GMV-SL-BANGO: Zone Bango - GMV-SL-PODOR: Pépinière Podor Louga: - GMV-LG-WIDOU: Zone Widou - GMV-LG-LOMPOUL: Zone Lompoul Tambacounda: - GMV-TB-BAKEL: Zone Bakel - GMV-TB-GOUDIRY: Zone Goudiry Dakar: - GMV-DG: Direction Nationale ``` ## Installation ```bash # 1. Configurer les variables d'environnement cp .env.example .env # Éditer avec vos paramètres MongoDB # 2. Installer les dépendances npm install # 3. Exécuter le seed GMV node server/seed-gmv.js # 4. Démarrer le serveur npm start ``` ## Comptes de connexion ### Direction ASERGMV (Superadmin) - Username: `directeur.gmv` - Password: `gmv2024!` - Accès: Toutes les zones ### Inspecteurs régionaux - **Saint-Louis**: `inspecteur.sl` / `gmv2024!` (Zones Rao, Bango, Podor) - **Louga**: `inspecteur.lg` / `gmv2024!` (Zones Widou, Lompoul) - **Tambacounda**: `inspecteur.tb` / `gmv2024!` (Zones Bakel, Goudiry) ### Chefs de zone - `chef.rao` / `gmv2024!` (Zone Rao) - `chef.bango` / `gmv2024!` (Zone Bango) - `chef.podor` / `gmv2024!` (Pépinière Podor) - `chef.widou` / `gmv2024!` (Zone Widou) - `chef.lompoul` / `gmv2024!` (Zone Lompoul) - `chef.bakel` / `gmv2024!` (Zone Bakel) - `chef.goudiry` / `gmv2024!` (Zone Goudiry) ### Pointeurs - `pointeur.rao` / `gmv2024!` (Zone Rao) - `pointeur.bango` / `gmv2024!` (Zone Bango) - `pointeur.widou` / `gmv2024!` (Zone Widou) - `pointeur.bakel` / `gmv2024!` (Zone Bakel) ## Horaires spécifiques - Zones de terrain: 7h00 - 16h00 (travail agricole commence tôt) - Direction Nationale: 8h00 - 17h00 ## Branding L'instance GMV utilise: - Couleur thème: `#2E7D32` (vert, cohérent avec l'environnement) - Titre: "SmartPointage — Grande Muraille Verte" - Badge instance: "Instance ASERGMV" ## Multi-tenant Les données GMV sont isolées avec le champ `tenant: 'gmv'` sur tous les documents (Users, Agents, Sites, Pointages). Cela permet: - De coexister avec d'autres clients (PAMECAS, etc.) - De déployer sur une URL dédiée: `gmv.smartpointage.sn` - Une isolation complète des données ## Déploiement 1. Créer une branche `gmv` dans le repository 2. Configurer les variables d'environnement spécifiques 3. Exécuter le seed GMV sur la base de données dédiée 4. Configurer le domaine `gmv.smartpointage.sn` ## Support Pour toute question technique: - Email: contact@smartpointage.sn - Téléphone: +221 77 388 62 07
