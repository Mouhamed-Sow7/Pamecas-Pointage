# SmartPointage Landing Page Site web one-page pour smartpointage.sn ## Structure ``` landing/ ├── index.html # Page principale ├── css/ │ └── style.css # Styles responsive ├── js/ │ └── main.js # Animations et formulaire ├── images/ # Mockups et logos (SVG inline) └── README.md ``` ## Sections de la page 1. **Header/Navigation** - Logo SmartPointage - Liens: Fonctionnalités, Tarifs, Clients, Contact - Bouton CTA "Demander une démo" - Navigation sticky au scroll 2. **Hero Section** - Titre principal - Sous-titre avec proposition de valeur - 2 boutons CTA - Mockup téléphone avec l'application kiosque - Badge clients (PAMECAS, GMV) 3. **Problème/Solution** - Comparaison avant/après SmartPointage - Listes des problèmes et solutions 4. **Fonctionnalités** - Grille 3x2 de cartes - Pointage QR Code - Mode Offline-First - Kiosque tablette - Dashboard temps réel - Rapports automatiques - Multi-tenant 5. **Cas d'usage clients** - PAMECAS (Microfinance) - Grande Muraille Verte (Reforestation) 6. **Tarifs** - Pro: 120 000 FCFA/mois/site - Enterprise: 180 000 FCFA/mois/site - 1er mois offert 7. **Comment ça marche** - 3 étapes simples 8. **Formulaire de contact** - Demande de démo - Validation côté client 9. **Footer** - Logo et tagline - CGU et confidentialité - Contact ## Technologies - HTML5 sémantique - CSS3 avec variables CSS - JavaScript vanilla (ES6+) - Google Fonts (Inter) - Aucune dépendance externe ## Déploiement ### GitHub Pages 1. Créer un repository `smartpointage-landing` 2. Pusher le contenu du dossier `landing/` 3. Activer GitHub Pages dans les settings ### OVH Hébergement statique 1. Uploader les fichiers via FTP 2. Configurer le domaine `smartpointage.sn` ## Personnalisation ### Couleurs Modifier les variables CSS dans `css/style.css`: ```css :root { --color-primary: #2E7D32; --color-primary-light: #4CAF50; --color-primary-dark: #1B5E20; --color-surface: #f8f9f8; } ``` ### Contenu Le contenu est directement dans `index.html`. Les icônes sont en SVG inline pour éviter les dépendances. ## Performances - Responsive mobile-first - Animations avec Intersection Observer - Lazy loading des images - CSS minimal (pas de framework) - Font display: swap pour Google Fonts ## Accessibilité - Navigation au clavier - Focus visible - Aria labels - Balises sémantiques - Respect de prefers-reduced-motion ## Contact contact@smartpointage.sn ## License © 2026 SmartPointage.
